Do this in order. Skip a layer and you will debug the wrong one.

## 1. Pick the GPU

- **32 GB local models:** [AMD Radeon AI PRO R9700](/gpus) (`gfx1201`). Official name — not an RX 9700.
- **16 GB is enough:** Radeon RX 9070 XT (also `gfx1201` on current matrices). Same generation, half the VRAM.
- **Already own a 7900 XTX:** still a practical home card (`gfx1100`). Different ROCm family package.

Read the [GPU directory](/gpus) and [Hardware](/hardware) before you buy a PSU. Estimate a fit on the [calculator](/calculator).

## 2. Install ROCm on Linux

Practical Ubuntu path (as of the [weekly card](/)):

1. Use an Ubuntu LTS **named on AMD’s current matrix**. ROCm 10.1.0 Radeon rows: **26.04.1, 24.04.5, 22.04.5**.
2. Add **AMD’s 10.1 repo** — or use **ROCm CLI v0.2.0** (`rocm install sdk`). Do not mix those with Ubuntu archive `rocm`.
3. Install **one** gfx family (gfx1201 on the R9700 — confirm with `apt-cache search`). Prefix: `ls /opt/rocm` (10.0 was often `/opt/rocm/core-10.0`).
4. **Do not** `apt install rocm` from Canonical’s archive.

Walkthrough: [Install ROCm](/tutorials/install-rocm). Prove it: [Verify GPU and ROCm](/tutorials/verify-rocm).

Before you rebuild the world: check **firmware / MES** after a kernel upgrade, and try **Vulkan llama.cpp** if HIP configure is a mess.

The [home status card](/) is the weekly pin. The [ROCm version notes](/rocm#version-notes) are history. Re-open AMD’s install page on the day you type commands.

## 3. Pick inference software

Consumer default on this site:

1. **llama.cpp** (Vulkan, or HIP `gfx1201`) — daily driver. Prefer that over official Ollama ROCm and over vLLM for a single-user box.
2. **Strata v0.1.42** — fast-agent try on our rig for Qwen 3.8 Flash.
3. **vLLM** — only when you need a multi-client server. **Try this week:** community / ROCm **0.31**. Conservative AMD pin on the 10.0 matrix is still **0.27**. Default `pip install vllm` is CUDA.

Compare them on [inference engines](/backends) and [AI software](/software). Run the daily driver: [Local LLM tutorial](/tutorials/run-local-llm) then [Serve Qwen](/tutorials/serve-qwen). Cards: [Recommended stacks](/stacks).

## 4. Optional harness

A **harness** is the agent loop *above* the model. It does not replace ROCm.

- **[Hermes Agent](/harnesses/hermes)** — used on our rig (local-desktop), pointed at Strata `:8083` and llama-server.
- **[OpenClaw](/harnesses/openclaw)** — self-hosted gateway into Discord/Telegram/etc.
- Chat UIs, IDE agents, and ComfyUI on ROCm: [harnesses catalog](/harnesses).

`curl` `/v1` first. Then point the harness at `127.0.0.1`. Snippets: [connect](/harnesses/connect).

## 5. Qwen

Default: **Qwen3.6-35B-A3B** Unsloth **UD-Q5_K_XL** on **one** R9700, llama.cpp Vulkan, 262144 context, f16 KV, no RAM offload. Measured on our rig, 2026-10: **100.8 tok/s** short context, **~88** at 32K, **~50** at 256K. Fast agents: **Qwen 3.8 Flash** UD-Q6_K_XL on Strata. Abliterated weights come after that pipe is boring.

## Stop conditions

- `rocminfo` has no `gfx1201` → do not download 20 GB.
- `rocm-smi` idle while you “generate” → you are on CPU.
- File is on a spinning disk → move it to NVMe before you tune flags.
- Harness is slow → check the **backend**, not the card’s reputation.
