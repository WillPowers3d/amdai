**Is “R9700 Pro” a real SKU?**  
The product is the **AMD Radeon AI PRO R9700**. There is no consumer RX 9700 in AMD’s current lineup. The gaming sibling is the RX 9070 series. [AMD GPUs](/gpus).

**Will ROCm work for local LLMs on Ubuntu in 2026?**  
Yes, for single-GPU inference, if you pin a current AMD **Core SDK** (10.0 line as of the [weekly card](/)) and a matching runtime. It is still not CUDA. Packaging is the hard part.

**Can I `apt install rocm` from Ubuntu?**  
You can. You should **not**, if you want Core SDK 10.0, `gfx1201`, or a current vLLM ROCm image. Canonical’s archive has lagged (e.g. **7.1** on 26.04). Add AMD’s 10.0 repo. [ROCm](/rocm).

**Windows?**  
Vulkan (llama.cpp, some UIs) is the honest path. Full ROCm userspace is a Linux product. Limited PyTorch-on-Windows exists; do not expect `rocm-smi` culture.

**Which Qwen should I run first?**  
**Being reworked.** There is no named 7B or 8B default on this pass. Prove GPU use on whatever official instruct the [weekly card](/) lists, then a coder SKU or [abliterated](/abliterated) if you want that tradeoff.

**vLLM 0.27, 0.29, or 0.30?**  
**0.27 + PyTorch 2.13** is AMD’s **10.0 supported combo** and the **reliability** serve pin this week (gfx1201 listed). Community ROCm Docker try-tag is now **`vllm/vllm-openai-rocm:v0.30.0`** (0.29.0 is the previous pin). Do not mix pins in one venv. Default PyPI vLLM is CUDA.

**Can I fine-tune like a 4090 blog post?**  
PyTorch ROCm exists. ROCm 10.0 has a known issue: training/fine-tune **GPU resets** on R9700 — try `TORCH_BLAS_PREFER_HIPBLASLT=0`. SGLang AITER may fail on this SKU. Community training writeups often use **ROCm 7.2.1**; keep **inference** on 10.0. The cookbook is thinner than CUDA.

**What is Radeon Stack Lab?**  
An Ubuntu **companion app** (Origin repo / local install — no public domain here) with a living catalog. Profile **`qwen-reliable`** is a slot **being reworked**. There is no `qwen3-8b-try` profile on this pass. [Stack Lab](/stack-lab).

**Do I need a harness?**  
No. You need tokens on the GPU. Hermes or OpenClaw come after a loopback `/v1` works. Local Hermes can draft the [weekday YAML scrape](/maintain); it does not publish.

**Is OpenClaw the same as Hermes?**  
No. Hermes is an agent product from Nous. OpenClaw is a multi-channel self-hosted gateway. [Harnesses](/harnesses).

**Will two R9700s double speed?**  
Not automatically. Expect RCCL and topology work. Measure. Qwen3.5 / 3.6 **27B** and **35B-A3B** are multi-GPU territory — not single-card defaults. A public llama.cpp multi-GPU writeup is not a one-R9700 recipe.
