These notes are the **written** weekly tracker. **Radeon Stack Lab** is the **Ubuntu companion app**: same living catalog, pickable profiles, run on the box that has the R9700.

It is an **independent** local app (Origin repo / local install). There is no public product domain to click. If you have the repo, run it next to this site. If you do not, this page is still the map of what the profiles mean.

<Callout type="note">
Named Qwen model slots are **being reworked**. There is no current `qwen3-8b-try` profile and no 7B instruct default on this pass. The [home status card](/) remains the pin if the app’s catalog and this YAML ever disagree — then refresh both.
</Callout>

## What it is for

| Piece | Job |
| --- | --- |
| **Living catalog** | The same weekly ROCm / vLLM / Qwen story as `src/data/what-works.yaml` |
| **`qwen-reliable`** | Default profile slot — **being reworked**. No named model this pass. |

The app does not replace ROCm, llama.cpp, or vLLM. It **selects a profile** and points you at a serve path those tools already understand.

## Profiles (conceptual)

### `qwen-reliable` — default (being reworked)

- **Model:** Being reworked
- **Quant / weights:** Being reworked
- **Serve:** ROCm Core SDK **10.0.0** + **vLLM 0.27** (10.0 matrix, `gfx1201` listed), or llama.cpp HIP / Vulkan — engine notes only; pick the model from a later catalog pass
- **Use when:** first tokens, overnight chat, anything you need to trust tomorrow morning — after a default is named again

Abliterated checkpoints are **not** a Stack Lab default profile. If you experiment, do it after a stock official instruct works — [Abliterated](/abliterated).
