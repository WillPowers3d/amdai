These notes are the **written** weekly tracker. **Radeon Stack Lab** is the **Ubuntu companion app**: same living catalog, pickable profiles, run on the box that has the R9700.

It is an **independent** local app (Origin repo / local install). There is no public product domain to click. If you have the repo, run it next to this site. If you do not, this page is still the map of what the profiles mean.

<Callout type="note">
Profiles follow the YAML. **`qwen-reliable`** is Qwen3.6-35B-A3B UD-Q5_K_XL on llama.cpp. **`qwen-fast-agent`** is Qwen 3.8 Flash UD-Q6_K_XL on Strata. The [home status card](/) wins if the app catalog and this YAML disagree — then refresh both.
</Callout>

## What it is for

| Piece | Job |
| --- | --- |
| **Living catalog** | The same weekly ROCm / Qwen story as `src/data/what-works.yaml` |
| **`qwen-reliable`** | Daily driver — Qwen3.6-35B-A3B UD-Q5_K_XL, llama.cpp Vulkan, one R9700, 262K, f16 KV |
| **`qwen-fast-agent`** | Fast agent — Qwen 3.8 Flash UD-Q6_K_XL, Strata v0.1.42 (llama.cpp Q6 fallback) |

The app does not replace ROCm, llama.cpp, or Strata. It **selects a profile** and points you at a serve path those tools already understand.
