These notes are the **written** weekly tracker. **Radeon Stack Lab** is the **Ubuntu companion app**: same living catalog, pickable profiles, run on the box that has the R9700.

It is an **independent** local app (Origin repo / local install). There is no public product domain to click. If you have the repo, run it next to this site. If you do not, this page is still the map of what the profiles mean.

<Callout type="note">
This site does not invent a download URL. Treat Stack Lab as “Origin repo / local app.” The [home status card](/) remains the pin if the app’s catalog and this YAML ever disagree — then refresh both.
</Callout>

## What it is for

| Piece | Job |
| --- | --- |
| **Living catalog** | The same weekly ROCm / vLLM / Qwen story as `src/data/what-works.yaml` |
| **`qwen-reliable`** | Default profile. Official instruct. Reliability first. |
| **`qwen3-8b-try`** | Cutting-edge profile. Newer Qwen3, uncertain on R9700. |

The app does not replace ROCm, llama.cpp, or vLLM. It **selects a profile** and points you at a serve path those tools already understand.

## Profiles (conceptual)

### `qwen-reliable` — default

- **Model:** [Qwen/Qwen2.5-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct)
- **Quant / weights:** BF16 on the AMD-aligned vLLM path; GGUF if you are on llama.cpp
- **Serve:** ROCm Core SDK **10.0.0** + **vLLM 0.27** (10.0 matrix, `gfx1201` listed), or llama.cpp HIP / Vulkan
- **Use when:** first tokens, overnight chat, anything you need to trust tomorrow morning

This is the same reliability pick as the [weekly card](/).

### `qwen3-8b-try` — cutting-edge

- **Model:** [Qwen/Qwen3-8B](https://huggingface.co/Qwen/Qwen3-8B)
- **Serve:** community **vLLM 0.29** ROCm Docker (`vllm/vllm-openai-rocm:v0.29.0`) or `wheels.vllm.ai/rocm/0.29.0/rocm723`
- **Use when:** you already proved `qwen-reliable`, and you want to smoke-test thinking / `/no_think`
- **Honesty:** uncertain on R9700. Not the default. Do not skip the 7B instruct for this.

Abliterated checkpoints are **not** a Stack Lab default profile. If you experiment, do it after official instruct works — [Abliterated](/abliterated).
