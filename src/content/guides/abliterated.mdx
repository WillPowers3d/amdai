**Abliterated** means *the refusals were edited in the weights* so a local open model is more likely to do the task you asked — on **your** machine, with no hosted safety API in the middle.

This page is technical and adult. Educational context only. You are responsible for what you run. We do not host weights.

<Callout type="note">
**Default stays official instruct.** Start from [Qwen2.5-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct) (`qwen-reliable` in [Stack Lab](/stack-lab)). An abliterated checkpoint is a *second* model after the GPU path is proven. This week’s notable 8B edit is Huihui-Qwen3-8B-abliterated-v2 — not a profile, not a default.
</Callout>

## What people are editing

Base chat models are trained to **refuse** some requests. A Hugging Face title that says “uncensored” can mean a system-prompt jailbreak, a small SFT, or a real weight edit. Read the card.

## Approaches (not a how-to)

| Approach | What it actually is | Limit |
| --- | --- | --- |
| **Abliteration** | Subtract / orthogonalize a refusal direction in activations (community “remove-refusals-with-transformers”, **Heretic**-style). No full retrain. | Think-loops, broken templates, dropped MTP/vision tensors |
| **Orthogonalization** | Same family: make residual streams less able to express “I can’t help.” | Quality is editor-dependent |
| **Uncensor SFT / LoRA** | Train on completions that fulfill where the base refused | Harness or system prompts can **restore** refusals |
| **Prompt jailbreaks** | A long persona in the chat template | Not a weight edit. Easy to undo. Easy to mistake for ablation |
| **No hosted safety layer** | Stock Qwen + llama.cpp on loopback already has no cloud moderator | Weights can still refuse |

## How to find them

Search Hugging Face for: `abliterated`, `uncensored`, `heretic`, `Huihui-Qwen`, `Huihui-Qwen3-8B-abliterated-v2`, `Qwen3.8-27B-Uncensored`.

Prefer the **publisher’s** card over a random re-quant. A published GGUF for the 8B v2 edit is `mradermacher/Huihui-Qwen3-8B-abliterated-v2-GGUF` — pin a revision. No download stats.

**Trust**

- SHA-256 or `huggingface-cli` revision pins, not “latest”
- Read **LICENSE** (Qwen base is often Apache-2.0; derivatives differ)
- If the card advertises MTP or vision, confirm those tensors survived
- Gated repos exist for a reason — read the note they make you click
