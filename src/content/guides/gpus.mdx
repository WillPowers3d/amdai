If you arrived here searching for an “AMD R9700 Pro,” you mean the **AMD Radeon AI PRO R9700**. There is no consumer **Radeon RX 9700**. The gaming sibling is the **Radeon RX 9070** series.

<Callout type="note" title="Official vs unofficial">
**Official** means the card is on AMD’s [ROCm 10.1.0 compatibility matrix](https://rocm.docs.amd.com/en/docs-10.1.0/compatibility/compatibility-matrix.html) or the [Linux system requirements](https://rocm.docs.amd.com/projects/install-on-linux/en/latest/reference/system-requirements.html) page. It is not a speed promise. **HSA_OVERRIDE_GFX_VERSION** is an unofficial way to boot a binary that did not list your gfx. Current `gfx1201` cards should not need it on ROCm 10.x. Why the IDs exist: [GPU architectures and gfx IDs](/rocm/gfx).

## What the Radeon AI PRO R9700 is

The [AMD Radeon AI PRO R9700](https://www.amd.com/en/products/graphics/workstations/radeon-ai-pro/ai-9000-series/amd-radeon-ai-pro-r9700.html) is a desktop **workstation / local-AI** card on **RDNA 4**. AMD places it in the Radeon AI PRO family — not Instinct, and not the RX gaming stack.

Public AMD product-page figures (verify there if you are buying):

| Item | AMD-published value |
| --- | --- |
| Architecture | AMD RDNA 4 |
| Compute units | 64 |
| Stream processors | 4096 |
| Dedicated memory | 32 GB GDDR6 |
| Memory bus | 256-bit |
| Peak memory bandwidth | 640 GB/s |
| Bus | PCIe 5.0 x16 |
| Total board power (TBP) | 300 W |
| Minimum PSU recommendation | 750 W |
| External power | 12V-2x6 |
| Memory ECC | Yes, Linux only |

ROCm documents the card as **LLVM target `gfx1201`**. On Core SDK **10.0 / 10.1** it is a first-class RDNA4 row with the RX 9000 series. If a tool does not mention `gfx1201` (or a generic gfx120x bucket), treat support as unproven.

Our test rig runs **two** of these and 256 GB DDR5. The [daily driver](/stacks) uses **one** card. Estimate a fit on the [calculator](/calculator).

## How AMD splits the brands

**Radeon RX (consumer).** Gaming cards. RDNA 4: RX 9070 XT / 9070 / 9070 GRE / 9060 XT. RDNA 3 workhorses: RX 7900 XTX / XT / GRE, RX 7800 XT.

**Radeon PRO / Radeon AI PRO (workstation).** Drivers aimed at professional apps and local inference. The R9700’s headline difference versus the RX 9070 XT is **capacity**: 32 GB vs 16 GB.

**Instinct (data center).** MI-series. Not a home-lab default.

AMD also states that Radeon PRO W6000 / W7000 and Radeon AI PRO R9000 cards (with some series exceptions) are **not designed or recommended for datacenter usage**.

## Buying notes that are not prices

- **VRAM is the constraint you feel first.** 8 GB, 16 GB, 24 GB, and 32 GB are different brackets once context grows. Use the [calculator](/calculator).
- **300 W TBP and a 750 W PSU recommendation** are AMD’s published figures for the R9700.
- **12V-2x6** is not the same cable culture as dual 8-pin PRO cards from last generation.
- Install **one** gfx family package (`gfx1201` vs `gfx110x`). Mixing them is how people get a CPU-only llama.cpp.
